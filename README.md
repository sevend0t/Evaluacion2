# Evaluacion2 - Sistema de Geolocalización y Rutas (Graphhopper)

Proyecto desarrollado para el curso de automatización y APIs, que permite calcular rutas óptimas, distancias, tiempos estimados y obtener la narrativa de viaje paso a paso utilizando la API de Graphhopper.

## Requisitos Previos
- Python 3 instalado.
- Librería `requests` (`pip install requests`).
- Una API Key válida de Graphhopper.

## Instrucciones de Ejecución
1. Clona o descarga este repositorio.
2. Asegúrate de configurar tu token de Graphhopper en la variable `KEY` dentro del script `geolocalizacion.py`.
3. Ejecuta el script desde la terminal con el comando:
   ```bash
   python3 geolocalizacion.py
